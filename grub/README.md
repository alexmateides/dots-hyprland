# CyberGRUB-2077

`CyberGRUB-2077/` is the GRUB theme **CyberGRUB-2077** by [adnksharp](https://github.com/adnksharp),
copied from <https://github.com/adnksharp/CyberGRUB-2077> (commit `d445dc3`, 2026-02-28) as its installer leaves it:
the theme directory with `img/logos/samurai.png` (the installer's default logo) as `logo.png`.
Released into the public domain under the [Unlicense](LICENSE); all credit for the artwork goes to the original author.

Installed by `scripts/setup_grub_theme.sh`; the plymouth theme in `plymouth/cybergrub-2077` reuses its images.
